Horizon Android Plus — CI run #39 fix

Cause:
The synced Nightly sources in crates/horizon-mods use the zip 9.x API
(ZipFile::name() returns a Result<Cow<str>>). The Android Plus manifest
still selected zip 2.x, where name() returns &str. This caused the
map_err()/into_owned() compiler errors in content.rs, index.rs,
index/native.rs and modpack.rs.

Change:
Update crates/horizon-mods/Cargo.toml from zip version "2" to "9.1.3",
matching Horizon Nightly's manifest and the existing zip 9.x dependency
used by horizon-server.

Apply from the repository root:
  git apply horizon-mods-zip9.patch

Then run a Cargo check/build so Cargo refreshes Cargo.lock, and commit
both crates/horizon-mods/Cargo.toml and Cargo.lock before running Actions.

This patch only changes the dependency version. It does not include an APK
or guarantee that no further compile errors will appear later in the build.
